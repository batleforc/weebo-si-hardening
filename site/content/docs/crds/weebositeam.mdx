- **Short names:** `wsteam`

`spec` of the `WeeboSiTeam` CRD.

## Example

```yaml
apiVersion: hardening.weebo.io/v1alpha1
kind: WeeboSiTeam
metadata:
  name: my-team
spec:
  namespaceSelector:
    matchLabels:
      weebo.io/team: team-1
```

| `warnLevel` | `string` | no |  | A Pod Security Standards level.<br /><br />**Lowercase on the wire, unlike every other enum in this CRD**, because these are upstream's values: the same spelling goes into the `pod-security.kubernetes.io/enforce` label, and an admin who writes `restricted` in a namespace label should not have to write `Restricted` here.<br /><br />The variant order is the strictness order, `Privileged < Baseline < Restricted`, so `Ord` answers "which is stricter" and [`Ord::max`] is "the stricter of the two".<br /><br />Values: `"privileged"`, `"baseline"`, `"restricted"` |
